## Этап 6. Разработка — компонент за компонентом

Реализовывать в следующем порядке (каждый следующий опирается на предыдущий):

### 6.1 Локализация
- `LocaleManager.java` — синглтон, `ObjectProperty<Locale>`, загрузка `ResourceBundle`
- Четыре файла `messages_*.properties` со всеми строками UI
- `LocalizedFormatter.java` — форматирование чисел и дат через `NumberFormat` / `DateTimeFormatter`

### 6.2 Точка входа
- `Launcher.java` — просто вызывает `App.main(args)`
- `App.java` — загружает `login.fxml`, создаёт Stage

### 6.3 Экран авторизации
- `login.fxml` + `LoginController.java`
- Использует существующие `ServerGateway`, `CommandParser`, `SessionContext`, `HashUtil`
- Смена языка в `ComboBox` → `LocaleManager.setLocale()` → `rebindLabels()`
- При успехе → переключить сцену на `main.fxml`

### 6.4 JavaFX-модель
- `HumanBeingFx.java` — `SimpleStringProperty`, `SimpleLongProperty` и т.д. для каждого поля
- Метод `matchesFilter(String text)` для Streams-фильтрации
- Статический метод `from(long key, HumanBeing hb, String ownerLogin)`

### 6.5 Утилиты визуализации
- `UserColorAssigner.java` — `Map<String, Color>`, автоназначение из палитры
- Базовые методы масштабирования координат в пиксели канваса

### 6.6 Canvas-компонент
- `CollectionCanvas.java` — рисует объекты: круг, позиция = координаты, радиус = impactSpeed
- Цвет заливки = `UserColorAssigner.getColor(ownerLogin)`
- `setOnMouseClicked` — найти ближайший объект, показать popup
- `setOnMouseClicked` (двойной) — открыть `EditDialog` для своего объекта
- Анимация добавления: `Timeline` с нарастанием радиуса от 0 до финального значения

### 6.7 Главное окно
- `main.fxml` + `MainController.java`
- `TableView<HumanBeingFx>` — колонка для каждого поля
- Фильтрация через `FilteredList` + Streams API предикат
- Сортировка через `SortedList`, привязанный к `tableView.comparatorProperty()`
- Тулбар: кнопка для каждой команды (insert, remove_key, clear, remove_lower, remove_greater_key, remove_all_by_minutes_of_waiting, info, help, execute_script, history, print_ascending, print_field_ascending_impact_speed)
- Автообновление: `ScheduledExecutorService` каждые 3 с → `show` → `Platform.runLater()` → `syncMasterList()`
- При закрытии окна: остановить поллер, закрыть `gateway`

### 6.8 Диалог редактирования
- `edit-dialog.fxml` + `EditDialogController.java`
- Открывается из таблицы (двойной клик) и с канваса
- Только для объектов с `ownerLogin == session.getLogin()`
- Поля: name, coordX, coordY, realHero, hasToothpick, impactSpeed, soundtrackName, minutesOfWaiting, mood, car
- «Сохранить» → `update {id}` команда → обновить объект в `masterList`

### 6.9 Стилизация
- `style.css` — базовые отступы, шрифты, цвета
- Убедиться, что интерфейс выглядит аккуратно на всех 4 локалях (разная длина строк)

**Результат:** полностью работающий GUI-клиент.
